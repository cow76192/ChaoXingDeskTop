# 桌面端 0.2.1 配置编辑与随机补全

日期：2026-10-13。

## 修复与新增

- 修复题库、AI、通知的参数输入框必须先启用服务才能编辑的问题。空闲时可以直接填写、修改和测试连接；仅在后台任务运行期间锁定配置。填写参数不会自动启用服务。
- 新增「答案处理 → 随机补全」，默认关闭，兼容旧设置文件；可以保存到本机。
- 执行顺序：题库 → AI → 人工补全 → 随机补全。已解决答案不会被随机答案覆盖。
- 随机补全支持单选、多选、判断题；没有选项的选择题、填空和简答保持待处理。
- 随机答案使用独立来源标记，不计入题库 / AI 命中率。只保存与自动提交由独立开关控制；仍有空白答案时仅保存。

## 验证

- 35 项单元与协议回归测试通过，包括默认关闭、旧配置迁移与保存、随机补全最后执行、不覆盖已有答案、题型限制、来源标记清理，以及实际答题表单中随机答案的保存 / 提交行为。
- Qt / QProcess 验收通过：默认关闭所有服务时，使用真实键盘事件编辑题库、AI 与通知输入框；任务运行时锁定、结束后恢复；随机补全开关保存；演示任务、停止与人工补全无回归。
- Windows EXE 与配套 worker 完整验收通过：协议模块与字体加载、默认关闭服务时可编辑参数、随机补全开关、3 门演示课程 / 9 个章节、重启与停止。

本次使用模拟接口与离线演示验证，不执行真实课程或付费题库 / AI 请求。
