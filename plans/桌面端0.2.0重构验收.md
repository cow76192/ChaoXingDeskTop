# 桌面端 0.2.0 重构

日期：2026-10-13。

## 产品行为

- 题库与 AI 分开配置，各题库使用独立凭据；通过勾选和排序控制启用与查询顺序。
- 所有已选题库先处理未解决题目，随后 AI 只处理仍未解决的题目。题库全部命中时不进行 AI 连接检查或 AI 请求。
- AI 请求失败时保留题库答案。图片识别为 AI 独立开关，关闭时不将图片题交给纯文本模型；LIKE 的图片开关仍独立配置。
- 人工补全窗口显示题目、选项和图片，并提供选择答案、跳过和停止；未开放章节通过按钮选择处理方式。
- 高级设置使用表单，不再提供 INI 代码编辑器；导入旧 INI 时迁移到桌面设置，所有页共用配置，统一保存。
- 未解决答案保留空白，全部题目解决后才允许自动提交；重复运行和重做不能绕过这一规则。

## 架构范围

桌面配置默认值不依赖旧配置模板，worker 不加载旧 main.py、不替换 builtins.input、不全局修改 requests.Session。桌面端自行实现任务调度、答题路由、AI 与 Qt 交互。删除旧 CLI、终端手动作答、旧 AI、标题缓存与终端进度辅助模块；清理不再需要的 OpenAI SDK、httpx 和 tqdm 直接依赖。

平台协议、题库接口和字体解码保留经过改编且注明来源的代码，仍有来源于参考项目的网络协议实现。此版本不宣称全部协议从零重写。

## 验证

- 单元与协议回归测试：29 项通过。包括全部题库先于 AI、仅缺失题目进入 AI、失败回退、非法答案继续补全、图片消息、纯文本图片题跳过、AI HTTP 请求与 JSON 解析、鉴权失败不重复请求且不泄露密钥、凭据隔离、旧配置迁移、导入空白处理、LIKE 布尔参数、未解决答案不随机填写且不强制提交。
- Qt / QProcess 离线验收通过：3 门演示课程、9 个章节、重启与停止、设置保存时排除秘密、表单导航、题库启用状态、人工单选与答案发送。
- 界面截图检查：980×700、1200×840、1600×900；题库与 AI 页面、高级设置、人工补全窗口均已生成截图，位于 plans/screenshots。
- 发布包验收通过：冻结程序协议模块导入、字体资源加载，以及实际 EXE / worker 的 3 门课程、9 个章节、重启与停止完整离线流程；界面截图位于 plans/release-smoke。

本次没有使用真实账号或付费服务凭据执行在线课程、题库和 AI 验收；真实接口、账户权限与所选模型视觉能力仍需部署环境实测。源码目录并非 Git 仓库，因此没有创建提交或 PR。
