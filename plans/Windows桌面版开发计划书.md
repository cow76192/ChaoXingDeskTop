# 超星桌面版开发计划书

编写日期：2026-10-13。状态：实施前计划，先于桌面版代码创建。

## 1. 目标与交付

将 Samueli924/chaoxing 的命令行功能改造成可直接双击使用的中文 Windows 桌面软件。默认目标系统为 Windows 10/11 x64。交付可运行源码、便携 EXE、构建脚本、使用说明和验收记录。本地没有账号，真实课程接口的验证需使用者登录后完成；开发期间使用明确标识的离线演示与模拟测试验证桌面流程。

检查发现：上游课程过滤在 ID 不匹配时会退回所有课程，桌面版必须精确匹配课程与班级，禁止意外全选；上游完成文案可能掩盖失败章节，桌面版按实际结果统计；上游日志可包含 Cookie，桌面版关闭其文件日志并过滤秘密。上游 `ask` 参数在当前队列中未实现询问，需要桌面适配。自动签到参数未接入主流程，不作为首版交付功能。

## 4. 技术方案

采用 Python 3.13 + PySide6，PyInstaller 生成 Windows 便携目录版。相比重写所有接口，可直接复用现有 Python 逻辑。GUI 使用 Qt 原生窗口、中文字体、清晰的导航与卡片布局。

目录结构：

```text
reference/chaoxing/           原样参考克隆，不在其中开发
plans/                       计划与验收记录
desktop/                     新桌面版工程
  chaoxing_desktop/           GUI、配置、运行控制、worker 适配
  vendor/chaoxing/            固定提交的上游核心与许可
  tests/                     配置、协议、任务状态和离线 GUI 测试
  scripts/                   打包脚本
  dist/                      Windows 可分发软件
```

主进程仅负责 UI，后台使用独立 worker 子进程，JSON Lines 管道传送事件、配置与交互回复。敏感参数通过 stdin 传递，不写入命令行或临时配置。worker 将标准输出与日志转成事件，GUI 不访问 worker 的线程对象。停止及关窗清理子进程，避免关闭界面后任务继续运行。

用户设置、Cookie、题库缓存放入本机用户数据目录，打包资源只读。配置导入支持 UTF-8 BOM；百分号不使用 INI 插值，适配 token 和 URL。普通保存排除账号密码、token、API key、通知 URL 等字段；完整配置导出明确标注包含秘密。

上游核心保留 GPL-3.0 LICENSE 和来源声明，桌面工程沿用 GPL-3.0，发布包提供源码与来源说明。许可说明以实际 LICENSE 为准。

## 5. 实施顺序

1. 已先创建 `reference` 和 `plans` 并完成克隆；完成本计划书。
2. 固定上游核心副本，建立桌面工程与依赖环境。
3. 实现配置模型、校验、去除敏感配置的持久化和运行事件协议。
4. 实现隔离 worker：登录/课程查询、精确课程选择、章节调度、交互、结果统计、停止。
5. 实现中文 GUI：账号与课程、学习设置、题库/通知、高级配置、任务与日志、离线演示。
6. 运行模拟/单元测试和 GUI 截图检查，修复后打包 EXE，验证 EXE 启动及 worker 模式。
7. 写入验收记录与用户使用说明。

## 6. 验收标准

- 计划书创建时间早于桌面代码。
- EXE 可从含中文与空格的路径启动，无需系统安装 Python。
- 无账号可完成离线演示；演示使用与真实模式相同的事件协议。
- 未登录或未选课程不能启动真实任务，过期课程选择不能变成全课程运行。
- 网络请求不阻塞窗口；停止后 worker 退出；重复开始不会产生多个 worker。
- 原 INI 可导入；表单/高级设置往返不丢未知字段；密码和 key 不在默认保存的文件与可导出日志中出现。
- 课程使用 courseId + clazzId 去重，章节完成/失败/关闭跳过分别统计。
- 手动输入请求可响应，取消不会自动提交；关闭窗口清理后台。
- 配置测试、worker 模拟运行测试、GUI 离线烟雾测试通过；可分发 EXE 启动检查通过。
- 不把模拟测试声称为真实账号接口验证。

## 7. 已知限制与后续方向

超星接口或题库服务发生变化时可能需要更新核心；验证码、课程权限与外部服务是否可用由实际服务决定。首版 OCR 为可选依赖，未装时使用上游提示到浏览器完成验证。停止不撤销已经发送的请求，重启后由平台实际进度判断完成状态。首版不承诺自动更新、系统托盘、跨设备账户同步、安装器或系统休眠后的自动恢复；这些可在桌面基础版本稳定后追加。
